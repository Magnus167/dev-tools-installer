For AI assistants and scripts

This page generates a bash script that installs common Linux developer tools (git, docker, ripgrep, node, kubectl and about 90 more) with apt, dnf, apk, pacman, zypper or yum. Everything runs in the browser; there is no server. The same generator is published next to this page as install.sh, so anything the page does also works from a terminal.

Files next to this page

  • llms.txt: how to read this site and answer install requests, in plain text.
  • tools.json: every tool id, its group, and how each package manager installs it, plus the combo-ID bit layout.
  • install.sh: the installer. --print shows the script it would run, --list lists the tools, --help shows usage.
  • SHA256SUMS: checksums of index.html, install.sh, tools.json and llms.txt for this version.

From a link to a command

A link to this page ends in a combo ID after the #: the package manager, a dash, and the picked tools as a base-36 bitmask (tools.json documents the bits). Pass the combo ID to install.sh from the same version directory. For example, the link https://magnus167.github.io/dev-tools-installer/__APP_VERSION__/#apt-2gosa7pa2h6 (git, docker and node on Debian or Ubuntu) is the same as:

curl -fsSL https://magnus167.github.io/dev-tools-installer/__APP_VERSION__/install.sh | bash -s -- apt-2gosa7pa2h6

If the part after the dash is exactly a tool id (say apt-jq), install.sh takes it for a typo of apt jq and stops; write a 0 after the dash (apt-0jq), which is the same combo.

Examples

# print the script for a combo ID and run nothing
curl -fsSL https://magnus167.github.io/dev-tools-installer/__APP_VERSION__/install.sh | bash -s -- --print apt-2gosa7pa2h6
# install by package manager and tool ids; add --no-shell to leave .bashrc and .zshrc alone
curl -fsSL https://magnus167.github.io/dev-tools-installer/__APP_VERSION__/install.sh | bash -s -- apt git docker node
# Alpine has no bash until the installer adds it, so pipe to sh (--print needs bash: use any machine with bash, or open the page link)
curl -fsSL https://magnus167.github.io/dev-tools-installer/__APP_VERSION__/install.sh | sh -s -- apk git jq
# list tool ids and how one package manager installs each
curl -fsSL https://magnus167.github.io/dev-tools-installer/__APP_VERSION__/install.sh | bash -s -- --list apt
# check a download against this version's checksums
curl -fsSL -O https://magnus167.github.io/dev-tools-installer/__APP_VERSION__/install.sh -O https://magnus167.github.io/dev-tools-installer/__APP_VERSION__/SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS

Read before you run

Don’t put sudo in front of the command: run it as the normal user (… | bash -s -- …, not … | sudo bash). The script installs system packages with sudo (or doas) itself and puts upstream tools under your home directory, mostly in ~/.local/bin; Go goes to /usr/local/go. Under sudo it stops with exit status 2 unless BOOTS_ALLOW_ROOT=1 is set. Before running it for someone, show them the script (--print, or this page with their link) and say what it will install. Versioned URLs (…/vX.Y.Z/) are built from that release’s git tag, so a pinned link keeps giving the same script.

Read any script before you run it. System packages are installed with sudo (or doas); tools fetched from upstream go under your home directory (mostly ~/.local/bin; nvm, SDKMAN and rustup keep their own folders), except Go in /usr/local/go. Each step skips anything already on your PATH, so running it twice is safe.
