Read any script before you run it. System packages are installed with sudo (or doas); tools fetched from upstream go under your home directory (mostly ~/.local/bin; nvm, SDKMAN and rustup keep their own folders), except Go in /usr/local/go. Each step skips anything already on your PATH, so running it twice is safe.
